# mygames

Simple browser games, hosted on GitHub Pages.

Play: https://ubuildmore.github.io/mygames/

- **Pong**: you vs. the computer. W/S or arrow keys (or drag on touch screens), Space to pause, first to 7 wins.
- **Bee Garden**: fly a bee around the garden and pollinate every flower (hover over each one until its ring fills) across 5 levels with wasps, sticky spider webs and wind. Arrow keys / WASD, or hold the mouse / your finger where the bee should go. Space / X (or the on-screen STING button) to sting wasps: one sting stuns, two drive them off. Beat the clock for a time bonus.
